# Изменения

## 1.1.0 — 08.10.2026

- Поиск всех Material блоков: `/cpv block all`, `/cpv blocks all`, `*`.
- Поиск всех онлайн- и офлайн-игроков из истории: `/cpv player all`.
- Кнопки «Все блоки» и «Все игроки» в GUI; `all` в tab completion.
- Поддержан вариант `/cpv bloks all`.
- Системные акторы CoreProtect (#fire/#tnt/#hopper) исключены из поиска всех игроков.
- Общий блоковый поиск адаптирован к ограничению API v12: положительный радиус,
  WORLD в допустимых координатах, ALL по загруженным мирам с единым лимитом.
- Контейнеры с неизвестным Material включаются в общий поиск блоков и
  сохраняют неизвестный тип без подмены перемещаемым предметом.
- Удалённые фильтры корректно показаны в меню; найденные игроки доступны в выборе.
- Публичная сборка получает compileOnly CoreProtect API из официального Maven.
- Добавлены тесты общего поиска и инструкция по публикации.

## 1.0.0 — 02.10.2026

- Первый выпуск: поиск конкретного игрока и блока, GUI, приватная визуализация,
  навигация, лимиты, отмена и реконструкция контейнерной истории.
